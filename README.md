# Resume Analyzer

A starter project structure for a resume analysis application with a Node.js backend, Java-based DSA examples, and project documentation.

## Structure

- backend/: Express.js-based API server
- dsa-java/: Java implementations of common data structures and algorithms
- docs/: Architecture and API documentation

## Getting Started

1. Open the backend folder and install dependencies.
2. Start the server with npm start.
3. Explore the Java examples in the dsa-java folder.
